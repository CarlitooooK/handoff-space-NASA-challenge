# Contratos

Aquí van las interfaces entre las partes, **copiadas desde su origen**:

- Una API: su especificación OpenAPI (`.yaml`).
- Un dataset: su esquema (JSON Schema, descripción de columnas).
- Un mensaje: ejemplos de cuerpo y de respuesta.

Cada archivo se anota en `docs/09-decisiones.md` con su fuente y versión. Si algo difiere del origen, manda el origen.
